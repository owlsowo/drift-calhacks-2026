Credits

Drift uses original generated coast artwork and a real WebGPU ocean simulation.

Moonlit coast and lighthouse
Original artwork created with OpenAI image generation, October 2026, from the team's visual brief. Separate landscape and portrait backgrounds provide the static fallback. A transparent headland sits over the animated water. Optimized WebP copies are bundled.
WebGPU ocean simulation
web-ocean by Maksymilian Dendura, copyright 2026, used under the MIT license. Based on upstream commit a07c7fd522ef0a897601c114f927a49d93d95520. The FFT ocean renderer is adapted with a fixed camera, blue-hour sky, moonlight and an independent lighthouse/headland overlay. The original scenery remains the fallback.
Wooden desk
Original moonlit wooden tabletop texture created with OpenAI image generation, October 2026. Optimized to WebP for the foreground controls.
Letter paper
Original cotton-paper texture created with OpenAI image generation, October 2026, used for writing, saved letters and exported images.
Message typeface
Kalam Regular by Indian Type Foundry, bundled locally under the SIL Open Font License. Controls use system fonts.
Crumpled paper ball
Paperball.png by Army1987, 2006. CC BY-SA 3.0. This legacy asset remains in the repository; the current bottle-opening view uses a vector bottle.
Paper texture
Free crumpled paper texture for layers, 2008, D Sharon Pruitt / Pink Sherbet Photography. CC BY 2.0. Resized and optimized. This legacy texture remains in the repository; current letters use the original cotton-paper texture.

Interface references

WeChat’s original Drift Bottle and QQ Mail’s bottle interface inspired the sea, bottom dock and opening ritual. Video supplied by the project owner. Their screenshots and video are references, not bundled assets.

The interactive bottle and dock controls are web components. The project is not affiliated with Tencent, WeChat, QQ or the photographers.
