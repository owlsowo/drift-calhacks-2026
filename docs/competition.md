# Competition plan — checked October 24, 2026

## Build one demonstrable interaction

Pitch: **A stranger starts a tiny story. You finish it. You both keep what you made.**

The software-only evidence case is a fresh-input, two-browser loop; actual subscriptions delivering a returned postcard; optional guidance grounded in the current setup; visible recovery and privacy boundaries; a legible exported artifact. No pilot is currently available. Do not claim reduced loneliness, lasting friendship, or observed attendee adoption.

Confirmed published sources disagree: the organizer guide includes Anthropic, Spacetime and Mana; the public Devpost list omits their explicit entries. Figma’s detailed brief lists workflow and stage-log awards while Devpost lists five different labels. Maximum entry count and stacking rules were not established. A human owner must confirm those narrow points before final submission.

Do not add finance, payments, web scraping, an extra database, or a runtime coding agent merely to claim more integrations. The current project has no essential role for those services. Gemini is conditional on a distinct useful feature, rather than duplicate moderation.

## Short demo

1. Writer A enters a fresh six-word setup and tosses it.
2. Writer B submits their own setup, catches A’s, and asks for a contextual nudge with a fresh draft.
3. Writer B writes their own ending and seals the postcard.
4. Show the finished card on B and its immediate return to A without refresh.
5. Save the image. Briefly show one privacy/failure boundary, then explain the architecture.

Any team starter is labeled. Any sandbox has a persistent visible notice. A recorded backup must say which calls were live and which content was seeded.
