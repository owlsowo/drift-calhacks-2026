# A shared daily tide

The shore now introduces the daily game before someone chooses an action: a tide edition, the shared theme, and “Six words from you. Six from someone else.” The approved sea and lighthouse remain the setting, with the same three bottle controls. A soft text scrim keeps the caption readable over bright water. Short landscape views omit the secondary premise line and hide the caption while the human-check panel needs that space.

The theme and tide date come from the subscribed server `today` row. The tide number is the shared date's edition relative to the existing October 24 UTC anchor, independent of visits or usage. Its machine-readable date stays with the `time` element. The client requests a refresh when its synchronized day differs from the server projection, using the existing server day/time procedures; the regular refresh remains a fallback. This is a shared daily prompt, not a local-time personal puzzle. How to play already displays the next reset in the visitor's local time.

The current six-check coast suite verifies the displayed theme against the server projection and checks caption/header/dock geometry across desktop, portrait, narrow phone and short landscape. It also retains real Chrome WebGPU movement/pause checks, responsive artwork fallback and WebKit/accessibility coverage. Five human-check layout checks and the current Chrome invitation flow pass. Browser viewports/failures are controlled tests, not physical-phone or overnight-user measurements. Build, script typechecks and CI are recorded with deployment evidence.

This applies the winner review's daily-identity recommendation to the existing game. Return cues continue to come from actual completed pairs and private ownership; this change creates no story, model call or synthetic engagement signal. The shared theme also gives the optional Claude guidance visible context. Track relevance remains a product argument, not proof of eligibility or social impact.
