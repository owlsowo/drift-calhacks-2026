# Shake a received bottle

The independent-letter redesign moved primary pickup into `BottleRitual`. The older Shore gesture was no longer reachable in that normal flow. This refinement restores the owner's WeChat/QQ-inspired physical interaction where the bottle is actually visible, over the same sea.

Hold and drag the bottle back and forth; four deliberate reversals open its note. The bottle follows a bounded drag and settles when released. One-way travel, an incomplete gesture and incidental pointer motion cannot count as a completed shake or become a tap after dragging. A normal tap or keyboard Enter opens immediately. Escape and Back to sea preserve the received assignment for resumption. The gesture does not dispatch another claim or paid request.

Coarse-pointer devices with a motion API offer **Enable phone shake**. Only that control requests permission. Denial or API failure leaves tap/drag available; a successful request restores focus to Open bottle. The opt-in is held only in memory for the current app page and has a **Turn off phone shake** control. No motion readings are stored or transmitted. Phone detection requires four alternating impulses above a threshold on the same axis; gravity-only devices prime a low-pass baseline from their first reading. Hidden-page transitions discard partial gestures. Pointer and phone readings do not combine. Reduced motion removes drag displacement and keeps the ordinary opening alternative.

`npm run test:ritual` and `DRIFT_TEST_ENGINE=webkit npm run test:ritual` each pass six current-flow checks, including one-way/incomplete drag, real pointer reversal opening, escape/focus/Enter, permission denial and failure, opt-in/weak/changing-axis/hidden inputs, turning motion off and reduced-motion tap. Selected Axe checks and visual review cover desktop, portrait phone and short landscape with and without phone controls. `npm test` passes 27 rules/contracts/storage/gesture checks, including fixed-axis and gravity-filter cases. The ten-check Chrome letter suite also passes after this change; the corresponding WebKit letter suite passed for the contribution refinement. Build and TypeScript checks pass.

These tests use synthetic local sample assignments with model calls disabled. Motion, permission outcomes and visibility transitions are injected; they are not physical-phone, native permission-sheet or attendee evidence. Older shore scripts still describe previous mechanics and are not passing release gates for this redesign. See the separate `bottle-ritual-{chrome,webkit}.json` reports and screenshots.

The change strengthens the recognizable bottle interaction for Creative/general judging and accessible alternatives for the People-First case. It adds no sponsor service and establishes no award eligibility or measured social benefit. See the sourced past-winner review for the product reasoning.
