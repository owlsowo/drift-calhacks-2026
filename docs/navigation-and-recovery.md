# Navigation and draft recovery

The address bar now follows the visible public beginning or completed pair. Home clears the previous story link, and My bottles uses `?view=bottles`. Browser Back/Forward and reload restore these views without starting a turn. A private editor keeps only its round ID in this browser history entry; neither the draft text nor private round ID enters a shared URL. The server still decides which private rounds this identity can read.

A completed note links back to its beginning and other endings. Its live count excludes the current pair and this viewer’s reports. Opening another ending selects that exact pair, so copying the address bar, reloading and using Back preserve the intended story.

Starting a beginning waits for the subscribed round, rather than requiring its reducer acknowledgement. Lost acknowledgements therefore cannot leave a committed turn spinning forever. Explicit failures and a bounded deadline restore controls. A late action cannot take over the screen after the reader navigates away.

An unfinished beginning from a closed day keeps its text and a Copy my draft action. Publication is disabled because today uses a different prompt. Start today’s beginning closes the old round, then resumes or creates a current one. The new draft starts empty; the old local draft remains available under the existing seven-day policy. A failed second step retains its error after returning to the shore. Existing cross-midnight reply leases remain valid until their actual expiry.
