# Product changes informed by past Cal Hacks winners

Reviewed October 24, 2026. This is a small, deliberately selected set of public project pages, not a comparison of all entrants. Winner badges establish the listed awards; feature descriptions are the teams' own reports. We have not independently run their products, watched all their videos, or established what caused the judges' decisions. These examples cannot produce a calibrated win probability or justify treating categories as independent chances.

## Product priorities

1. **Make contribution visible.** This change adds a quiet author-aware note footer: the beginning's author and the ending's author see the appropriate contribution, while public/bookmark-only readers get a neutral two-writer caption. Samples and team beginnings keep separate provenance. The PNG has a neutral caption and photographic attribution; copied peer text remains just the two creative lines. This directly clarifies the human collaboration for Meta, People-First, Creative and general judging.
2. **Restore the tactile gesture in the new ritual.** The redesign's primary pickup uses BottleRitual, while the older gesture code remains in Shore's catch screen. Verify the current reachable path and restore pointer/opt-in phone input where the bottle is actually shown. Keep tap and keyboard alternatives. Implemented and checked in the current refinement; see `bottle-ritual-shake.md` for browser coverage and the remaining physical-phone limit.
3. **Make a specific beginning easy to co-write.** Evaluate an optional public invitation to add an ending to a currently open beginning. It could shorten the two-device demo and quiet-sea participation without simulated strangers. Day, quota, self-reply, duplicate and report boundaries must remain authoritative. Not implemented yet.
4. **Verify the new hosted model loop.** The migration and local multi-writer flows pass, but the new semantics still need a purpose-limited hosted call/return check. Separate it from the earlier hosted checks; preserve synthetic labels and remove test inventory afterward. Do not present software checks as attendee outcomes or spend more evaluation credits casually.
5. **Finish the retry-cache retention gap.** A transport failure can leave a plain-text retry record beyond draft expiry. Apply the existing bounded local retention to those records without changing idempotent retry behavior. Identified during inspection; still pending.

Figma/Mana remain actual workflow contributions with their existing accessible artifacts. Adding unrelated databases, payments, voice or generated people would weaken the core experience and does not follow from this sample. Submission writing remains the team's responsibility.
